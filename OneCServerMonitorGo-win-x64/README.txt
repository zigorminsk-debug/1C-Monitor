1C Server Monitor — версия на Go + Fyne (x64)

Запуск: 1C-Server-Monitor-Go.exe, для администрирования — от имени администратора.
Установка и .NET не нужны. Требуется Windows 10 / Windows Server 2016 или новее.

Интерфейсу нужен OpenGL 2.1. Если программа запускается в сеансе RDP или на виртуальной машине
без драйвера видеокарты, вместо главного окна появится сообщение с вариантами решения.

Настройки и история общие с версией на .NET: %LOCALAPPDATA%\1CServerMonitor
Журналы запуска: interface.log и crash.log в том же каталоге.

Исходный код и сборка: каталог OneCMonitorGo, файл README.md.
