# История изменений (Changelog)

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование следует [SemVer](https://semver.org/lang/ru/).

## [1.6.0] — 2026-11-26

### Добавлено
- **Полноценный графический интерфейс (GUI) для `1C-Watchdog.exe`**:
  - При двойном клике по `1C-Watchdog.exe` (или запуске с `--gui`) открывается самостоятельная панель настройки и управления службой на базе Avalonia UI (`WinExe` со встроенной иконкой приложения).
  - Вкладка **«Служба и статус»**: статус `1CServerWatchdog` (`LocalSystem`), кнопка перезапуска с правами администратора (UAC), установка/обновление/запуск/остановка/перезапуск/удаление службы с подтверждением, журнал операций и кнопка **«Проверить сеансы сейчас (Dry-Run)»** с таблицей кандидатов на завершение.
  - Вкладка **«Подключение 1С»**: автопоиск `rac.exe`, запуск `ras.exe`, адреса RAS и агента кластера, DPAPI-шифрование пароля кластера, таймауты, `AutoStartRas`, `RestartHungRas`, `MonitorAllClusters` и список целевых кластеров + проверка подключения.
  - Вкладка **«Правила контроля»**: интервал, режим `DryRun`, политики дубликатов (`Full`, `UserAndBase`, `UserBaseApp`, минимальный возраст и число сохраняемых сеансов), пороги зависших сеансов (вызов, СУБД, блокировка, спящие, `TerminateHungOnlyWhenBlockingOthers`), `ConsecutiveChecksRequired`, исключения (`Designer`, `BackgroundJob`, пользователи, базы) и белый список `TargetInfoBases`.
  - Вкладка **«Уведомления и обновления»**: настройки Telegram / HTTP Webhook / SMTP Email с тестовой отправкой, автообновление через GitHub Releases (включая `pre-release` и просмотр Release Notes) и параметры хранения логов.
  - Вкладка **«Журнал работы»**: просмотр логов `%ProgramData%\1CServerMonitor\logs\watchdog-*.log` с фильтром по уровню (`Все`, `WARN`, `ERROR`), текстовым поиском, автообновлением и открытием папки/файла.
- **Полная обратная совместимость с Windows Service и CLI**: при запуске от SCM (`--service`) работает в headless-режиме без инициализации GUI; консольные флаги (`--setup`, `--uninstall`, `--status`, `--check-update`, `--console`, `--help`) автоматически подключают консоль (`AttachConsole`/`AllocConsole`).
- **Интеграция с `1C-Server-Monitor.exe`**: кнопка настройки Watchdog во вкладках «Администрирование» и «Служба Watchdog» теперь запускает графическую панель `1C-Watchdog.exe --gui` с запросом UAC.

### Исправлено
- Исправлена передача аргументов в `sc.exe` (`binPath=`, `start=`, `depend=`, `obj=`, `DisplayName=`, `reset=`, `actions=` как отдельные токены `ArgumentList`) — ранее `sc.exe create/config` мог завершаться ошибкой при регистрации службы Windows из-за склеенных ключей и значений.
- В `1C-Server-Monitor.exe` исправлена проверка и управление состоянием службы `1CServerWatchdog` (прямой разбор кода возврата `sc.exe query` и корректная проверка `ExitCode` при запуске/остановке службы без ложного сообщения «Команда выполнена» при ошибке).

## [1.5.0] — 2026-11-26

### Добавлено
- **Вкладка «Служба Watchdog» в GUI**: статус службы `1CServerWatchdog` (`LocalSystem`), запуск/остановка/перезапуск, полный редактор политик `watchdog.json` (группировка дубликатов, grace checks, whitelist/blacklist баз, DryRun, все кластеры) и просмотр последних логов `%ProgramData%\1CServerMonitor\logs` прямо в интерфейсе.
- **Графики в реальном времени** (`MetricsChartControl`): отображение последних 240 замеров CPU `rphost`, диска, сети и активных сеансов во вкладке «Обзор».
- **Поиск, фильтры и контекстное меню сеансов**: фильтрация по тексту, активным/блокированным/дубликатам; завершение выбранного сеанса или всех сеансов пользователя с модальным подтверждением, переход к процессу `rphost` и копирование UUID / запроса СУБД.
- **Системный трей (`TrayIcon`)**: сворачивание при закрытии окна для сохранения работы суточного отчёта (`23:55`), быстрое меню управления в трее.
- **Оповещения (Telegram / Webhook / Email SMTP)**: отправка уведомлений о критических тревогах, срабатываниях Watchdog и выходе новых версий (секреты шифруются Windows DPAPI).
- **Улучшенный `SessionAnalyzer` и `RacClient`**:
  - Режимы группировки дубликатов (`Full`, `UserAndBase`, `UserBaseApp`), grace period (`ConsecutiveChecksRequired`), условие `TerminateHungOnlyWhenBlockingOthers` и белый список `TargetInfoBases`.
  - Мониторинг нескольких кластеров (`MonitorAllClusters` / `TargetClusters`) и автоматический перезапуск зависшего `ras.exe` с экспоненциальным backoff.
  - Отложенный автозапуск службы Watchdog (`start= delayed-auto`, `depend= Tcpip`).
- **Откат и pre-release в `GitHubAutoUpdater`**: проверка работоспособности после замены exe/перезапуска службы с автоматическим восстановлением резервной копии при сбое, канал pre-release и отображение Release Notes в GUI.
- **Набор модульных тестов `OneCMonitor.Tests`** (xUnit) с запуском `dotnet test` в CI.

## [1.4.0] — 2026-11-26

### Добавлено
- **Общая библиотека `OneCMonitor.Core`**: вынесены клиент `RacClient` (`rac.exe`/`ras.exe`, автоопределение кодировки), анализатор сеансов `SessionAnalyzer`, защита секретов Windows DPAPI `SecretProtector` и механизм автообновления `GitHubAutoUpdater`.
- **Отдельная системная служба `OneCWatchdog` (`1C-Watchdog.exe`)**:
  - Регистрация и работа как системной службы Windows (`LocalSystem`) с автозапуском и политикой восстановления SCM при сбоях.
  - Мастер установки `--setup` с автоповышением прав UAC, настройкой защищённых NTFS ACL (`SYSTEM` + `Administrators`), регистрацией источника Event Log (`1CServerWatchdog`) и DPAPI-шифрованием учётных данных.
  - Автоматическое отслеживание и завершение дублирующихся ранних сеансов и зависших сеансов (долгие вызовы, блокировки, длительные спящие сеансы), поддержка режима `DryRun`.
  - Ежедневные ротируемые логи в `%ProgramData%\1CServerMonitor\logs` и запись событий в журнал Windows.
  - PowerShell-обёртка установки `scripts/install-watchdog.ps1` и кнопка запуска установки службы из вкладки «Администрирование» в GUI.
- **Автообновление с GitHub Releases**:
  - Проверка новых версий на GitHub Releases, загрузка и верификация SHA-256 по `SHA256SUMS.txt`, безопасное фоновое обновление как для GUI (`1C-Server-Monitor.exe`), так и для службы Windows (`1C-Watchdog.exe`).
  - Поддержка приватных репозиториев GitHub через DPAPI-защищённый токен доступа в настройках.

### Изменено
- `OneCMonitor.sln`, `scripts/publish.ps1`, `.github/workflows/ci.yml` и `.github/workflows/release.yml` обновлены для совместной сборки и публикации `1C-Server-Monitor.exe` и `1C-Watchdog.exe` (`win-x64` и `win-x86`).

## [1.3.1] — 2026-10-02

### Оптимизации производительности
- Разделены интервалы опроса: локальные CPU/RAM/диск/сеть опрашиваются каждые **5 с**, `rac.exe` — каждые **15 с**, техжурнал — каждые **60 с**, запись CSV и суточной статистики — каждые **60 с**.
- Добавлено кэширование последнего снимка RAC (при временной ошибке отображаются последние полученные данные).
- Опрос кластеров начинается с последнего успешного кластера; остальные опрашиваются только если он пуст или недоступен.
- Поиск `rac.exe` / `ras.exe` кэшируется на 10 минут (включая пустой результат); убран неограниченный `SearchOption.AllDirectories`, обход ограничен глубиной 2 и лимитом в 500 каталогов.
- Список файлов технологического журнала кэшируется на 10 минут; читаются 8 последних файлов по 128 КБ.
- История в памяти ограничена 12 000 точек с шагом сохранения 10 секунд.
- Таблица сеансов обновляется только при новом снимке RAC или ручном обновлении.
- Повторение одинаковых тревог подавляется на 300 секунд, повторяющихся ошибок RAC в журнале — на 5 минут.
- Статические параметры ОС/CPU кэшируются; сводка томов обновляется раз в минуту.
- Сопоставление сеансов с PID переведено на словарь; устаревшие CPU-снимки завершившихся PID очищаются.
