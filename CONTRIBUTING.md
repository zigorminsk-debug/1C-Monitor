# Руководство для контрибьюторов

Спасибо за интерес к развитию **1C Server Monitor**!

## Среда разработки
- **.NET 8.0 SDK**
- **IDE**: Visual Studio 2022, JetBrains Rider или VS Code с расширением C# Dev Kit.
- **ОС**: сборка возможна на любой платформе, но для полного тестирования (Windows PDH, реестр, `rac.exe`/`ras.exe`, службы `ragent.exe`) требуется Windows.

## Стандарты кода
1. Соблюдайте правила форматирования из `.editorconfig` (UTF-8, отступы 4 пробела для C# и 2 пробела для AXAML/XML/YAML).
2. Код должен собираться без ошибок и предупреждений в конфигурации `Release`:
   ```bash
   dotnet build OneCMonitor.sln -c Release
   ```
3. Проверяйте публикацию single-file сборок для обеих архитектур (`win-x64` и `win-x86`):
   ```powershell
   .\scripts\publish.ps1
   ```
4. Не коммитьте:
   - папки `bin/`, `obj/`, `artifacts/`, `publish/`;
   - файлы с реальными отчётами, логами, дампы с именами пользователей или серверов (`1C-monitor-*.html`, `last-rac-diagnostic.txt`, `settings.json`);
   - учётные данные, пароли кластера 1С и приватные ключи.

## Процесс внесения изменений
1. Создайте ветку от актуальной `main`.
2. Внесите изменения и проверьте сборку.
3. Обновите `CHANGELOG.md` (раздел `[Unreleased]`) и при необходимости `README.md`.
4. Откройте Pull Request и заполните шаблон PR.
