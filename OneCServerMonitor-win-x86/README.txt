1C SERVER MONITOR 1.5.0 — WINDOWS x86
=====================================

Сводный выпуск: объединены наработки всех веток, включая подключение к SQL
и кнопку «Выход».

НОВОЕ
- Кнопка «Выход» в шапке с диалогом подтверждения: останавливает мониторинг и
  закрывает программу, завершая все процессы, запущенные монитором (rac.exe,
  powershell.exe, ras.exe от «Запустить RAS»). Процессы 1С не затрагиваются.
  Закрытие окна крестиком идёт тем же путём остановки; настройки сохраняются.
- Подключение к серверу SQL — диск базы данных: очередь и нагрузка диска
  опрашиваются только по диску, на котором развёрнута база (sys.master_files).
  Галочка «Учётные данные Windows», кнопка «Проверить соединение и сохранить»,
  авто-перепроверка диска каждые 5 минут; без подключения — счётчик _Total.
- Ручной выбор дисков для мониторинга чекбоксами (приоритет над диском SQL).
- Автозавершение спящих сеансов (вкл/выкл) при каждом опросе RAC, без контрольной фразы.
- Расшифровка выполняемого вызова: документ/модуль и таблицы СУБД (контекст ТЖ
  и текущий запрос СУБД), колонка «Выполняется в вызове».
- Расшифровка блокировок: таблицы, модули и документы из событий TLOCK/DEADLOCK
  ТЖ по номеру соединения RAC; колонка «Расшифровка блокировки», карточка
  «Сеансы с блокировками», раздел блокировок в HTML-отчётах.
- Человекочитаемые имена служб и операций сервера 1С; PID в тревогах и статусе
  самодостаточен (по нему видны CPU, память, сеансы и пользователи процесса).
- Суточный отчёт: дата и время пика напротив виновника нагрузки и раздел
  «Выводы и рекомендации»; информация по диску в обзоре больше не обрезается.
- CI: сборка win-x64/win-x86 через GitHub Actions, артефакты и релиз по тегу.
