1C Server Monitor — версия на Go + Fyne (x86)

Запуск: 1C-Server-Monitor-Go.exe, для администрирования — от имени администратора.
Установка и .NET не нужны. Требуется Windows 10 / Windows Server 2016 или новее.

Интерфейсу нужен OpenGL 2.1. Если программа запускается в сеансе RDP или на виртуальной машине
без драйвера видеокарты, вместо главного окна может появиться сообщение об ошибке. Тогда нужна
программная отрисовка Mesa3D: https://github.com/pal1000/mesa-dist-win/releases
(архив mesa3d-...-release-mingw.7z). Скопируйте из папки x86 архива файлы opengl32.dll,
libgallium_wgl.dll и dxil.dll в каталог с программой. Либо установите Mesa3D для всей системы:
запустите из архива systemwidedeploy.cmd от имени администратора и выберите пункт 1.
С 32-битной программой Mesa3D не проверялась; на 64-битном сервере берите сборку x64.

Вкладка «Графики нагрузки» показывает процессор, память и диск во времени; щелчок по пику
показывает программы Windows и действия 1С, работавшие в этот момент.

Настройки и история общие с версией на .NET: %LOCALAPPDATA%\1CServerMonitor
Журналы запуска: interface.log и crash.log в том же каталоге.

Исходный код и сборка: каталог OneCMonitorGo, файл README.md.
