1C SERVER MONITOR 1.5.0 — WINDOWS x64
=====================================

Сводный выпуск: объединены наработки всех веток, включая подключение к SQL
и кнопку «Выход».

НОВОЕ
- Кнопка «Выход» в шапке с диалогом подтверждения: останавливает мониторинг и
  закрывает программу, завершая все процессы, запущенные монитором (rac.exe,
  powershell.exe, ras.exe от «Запустить RAS»). Процессы 1С не затрагиваются.
  Закрытие окна крестиком идёт тем же путём остановки; настройки сохраняются.
- Подключение к серверу SQL — диск базы данных: очередь и нагрузка диска
  опрашиваются только по диску, на котором развёрнута база (sys.master_files).
  Галочка «Учётные данные Windows», кнопка «Проверить соединение и сохранить»,
  авто-перепроверка диска каждые 5 минут; без подключения — счётчик _Total.
- Ручной выбор дисков для мониторинга чекбоксами (приоритет над диском SQL).
- Автозавершение спящих сеансов (вкл/выкл) при каждом опросе RAC, без контрольной фразы.
- Расшифровка выполняемого вызова: документ/модуль и таблицы СУБД (контекст ТЖ
  и текущий запрос СУБД), колонка «Выполняется в вызове».
- Расшифровка блокировок: таблицы, модули и документы из событий TLOCK/DEADLOCK
  ТЖ по номеру соединения RAC; колонка «Расшифровка блокировки», карточка
  «Сеансы с блокировками», раздел блокировок в HTML-отчётах.
- Человекочитаемые имена служб и операций сервера 1С; PID в тревогах и статусе
  самодостаточен (по нему видны CPU, память, сеансы и пользователи процесса).
- Суточный отчёт: дата и время пика напротив виновника нагрузки и раздел
  «Выводы и рекомендации»; информация по диску в обзоре больше не обрезается.
- CI: сборка win-x64/win-x86 через GitHub Actions, артефакты и релиз по тегу.

SHA-256 сборок 1.5.0 будет добавлен после публикации. Ниже — заметки выпуска 1.3.1.

1C SERVER MONITOR 1.3.1 — WINDOWS x64
=====================================

Проведён полный аудит основного цикла мониторинга и снижена фоновая нагрузка CPU/диска.

ОПТИМИЗАЦИИ
- Локальные CPU/RAM/диск/сеть опрашиваются отдельно от тяжёлого RAC.
- RAC по умолчанию запускается раз в 15 секунд вместо каждого 5-секундного такта.
- Последний снимок RAC кэшируется; при временной ошибке показываются последние данные.
- Успешный кластер проверяется первым; остальные кластеры опрашиваются только если он пуст/недоступен.
- Поиск rac.exe/ras.exe кэшируется на 10 минут.
- Удалён неограниченный SearchOption.AllDirectories по каталогам 1C на дисках; поиск ограничен типовой глубиной и 500 каталогами.
- Пустой результат поиска тоже кэшируется, исключая повторное сканирование каждые несколько секунд.
- Технологический журнал по умолчанию анализируется раз в 60 секунд.
- Список файлов техжурнала кэшируется на 10 минут; читаются 8 последних файлов по 128 КБ вместо 12 по 512 КБ.
- История в памяти сохраняется раз в 10 секунд, максимум 12000 точек.
- CSV и суточная статистика записываются раз в 60 секунд вместо каждого такта.
- Таблица сеансов перерисовывается только при новом снимке RAC.
- Повтор одинаковой тревоги по умолчанию не чаще одного раза в 300 секунд.
- Статические параметры ОС/CPU кэшируются; тома обновляются раз в минуту.
- Сопоставление сеансов с PID переведено с повторных линейных проходов на словарь.
- Удаляются устаревшие CPU-снимки исчезнувших PID.
- Повторяющиеся ошибки RAC в журнале подавляются на 5 минут.

НАСТРОЙКИ ПРОИЗВОДИТЕЛЬНОСТИ ПО УМОЛЧАНИЮ
- локальные метрики: 5 секунд;
- RAC: 15 секунд;
- техжурнал: 60 секунд;
- запись истории: 60 секунд;
- одинаковая тревога: 300 секунд.

Все интервалы доступны в «Настройки → Производительность монитора».

ПРОВЕРКА
- dotnet build Release: успешно;
- предупреждения: 0;
- ошибки: 0;
- self-contained win-x86/win-x64: успешно.
