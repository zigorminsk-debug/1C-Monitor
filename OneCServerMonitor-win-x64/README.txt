1C SERVER MONITOR 1.4.0 — WINDOWS x64
=====================================

НОВОЕ
- Кнопка «Выход» в шапке: останавливает мониторинг и закрывает программу,
  завершая все процессы, запущенные монитором (rac.exe, powershell.exe, а также
  ras.exe, поднятый кнопкой «Запустить RAS»). Процессы 1С (rphost/1cv8) не затрагиваются.
- Диалог подтверждения при выходе по кнопке: случайное нажатие не обрывает
  накопление суточной истории, выход можно отменить («Продолжить мониторинг»).
- Закрытие окна крестиком идёт тем же путём остановки: отменяется цикл мониторинга
  и завершаются дочерние процессы монитора; настройки сохраняются при выходе.
- Страховка от зависшего диспетчера: Environment.Exit(0) через 4 секунды после выхода.

SHA-256 сборок 1.4.0 будет добавлен после публикации. Ниже — заметки выпуска 1.3.1.

1C SERVER MONITOR 1.3.1 — WINDOWS x64
=====================================

Проведён полный аудит основного цикла мониторинга и снижена фоновая нагрузка CPU/диска.

ОПТИМИЗАЦИИ
- Локальные CPU/RAM/диск/сеть опрашиваются отдельно от тяжёлого RAC.
- RAC по умолчанию запускается раз в 15 секунд вместо каждого 5-секундного такта.
- Последний снимок RAC кэшируется; при временной ошибке показываются последние данные.
- Успешный кластер проверяется первым; остальные кластеры опрашиваются только если он пуст/недоступен.
- Поиск rac.exe/ras.exe кэшируется на 10 минут.
- Удалён неограниченный SearchOption.AllDirectories по каталогам 1C на дисках; поиск ограничен типовой глубиной и 500 каталогами.
- Пустой результат поиска тоже кэшируется, исключая повторное сканирование каждые несколько секунд.
- Технологический журнал по умолчанию анализируется раз в 60 секунд.
- Список файлов техжурнала кэшируется на 10 минут; читаются 8 последних файлов по 128 КБ вместо 12 по 512 КБ.
- История в памяти сохраняется раз в 10 секунд, максимум 12000 точек.
- CSV и суточная статистика записываются раз в 60 секунд вместо каждого такта.
- Таблица сеансов перерисовывается только при новом снимке RAC.
- Повтор одинаковой тревоги по умолчанию не чаще одного раза в 300 секунд.
- Статические параметры ОС/CPU кэшируются; тома обновляются раз в минуту.
- Сопоставление сеансов с PID переведено с повторных линейных проходов на словарь.
- Удаляются устаревшие CPU-снимки исчезнувших PID.
- Повторяющиеся ошибки RAC в журнале подавляются на 5 минут.

НАСТРОЙКИ ПРОИЗВОДИТЕЛЬНОСТИ ПО УМОЛЧАНИЮ
- локальные метрики: 5 секунд;
- RAC: 15 секунд;
- техжурнал: 60 секунд;
- запись истории: 60 секунд;
- одинаковая тревога: 300 секунд.

Все интервалы доступны в «Настройки → Производительность монитора».
